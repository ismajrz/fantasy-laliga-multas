# Fantasy LaLiga: multas entre amigos

Una web sencilla para llevar las multas de una liga de LaLiga Fantasy entre amigos.

## Cómo funciona

- En cada jornada pagan los últimos puestos de la liga, cada uno una cantidad distinta.
- Si hay empate, los empatados se reparten la multa a partes iguales.
- Durante la temporada no se paga nada: la web solo apunta quién debe qué y se salda todo al final.

## Qué se puede hacer

- Ver cuánto dinero hay en el bote y quién debe más.
- Apuntar los últimos de cada jornada.
- Ver estadísticas: rachas y cómo crece el bote.
- Ver el historial de cambios de cada jornada.
- Avisar al grupo de WhatsApp con un botón.
- Instalarla en el móvil como si fuera una app.

## Seguridad y copias

- Corregir o borrar una jornada ya apuntada solo se puede sin PIN durante 15 minutos y desde el mismo móvil; después hace falta el PIN de administrador.
- Se guarda una copia de seguridad automática cada semana y otra antes de cada cambio.
